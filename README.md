#Rubydung Plus

Rubydung Plus is an expansion mod for the early build of Minecraft, historically known as RubyDung. The project aims to significantly broaden the scope of the classic game while preserving its original atmosphere.

Key Features:

New Blocks & Structures: A variety of new blocks for building and dynamic world-generation structures to explore.

New Mobs: Unique creatures and entities that make the world feel alive and challenging.

Expanded World Generation: New environments and custom worlds to explore beyond the classic boundaries.

Full Inventory System: A complete and functional inventory interface for gathering and managing resources.

Multiplayer (In Development): A network mode is currently being developed, bringing multiplayer support in upcoming updates!
